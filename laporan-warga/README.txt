CARA PAKAI (XAMPP / Laragon)
1. Salin folder ini ke htdocs (XAMPP) atau www (Laragon), mis. htdocs/laporan-warga
2. Buka phpMyAdmin > Import > pilih database.sql
3. Cek koneksi DB di config.php (default: user root, password kosong)
4. Buka http://localhost/laporan-warga
